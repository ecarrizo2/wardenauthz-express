# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in WardenAuthz, please report it
privately. **Do not open a public issue.**

Email: security@wardenauthz.com

We will acknowledge your report within 48 hours and provide a timeline for
resolution within 5 business days.

## Supported Versions

| Version | Supported |
|---------|-----------|
| latest  | ✅        |

## Disclosure Policy

We follow coordinated disclosure. Once a fix is released, we will publish a
security advisory with credit to the reporter (unless anonymity is requested).
